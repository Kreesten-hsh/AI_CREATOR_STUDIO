# Acquisition de Références Virales (Antigravity)

Les meilleurs carrousels naissent en étudiant **la structure d'outliers prouvés** (idéalement hors de notre niche : fitness, cuisine, voyage, productivité, design) avant d'écrire la première ligne.

---

## 3 Routes dans Antigravity (Par ordre de simplicité)

### Route 1 — Captures d'écran collées (Recommandée / 100 % gratuite)
1. L'utilisateur trouve un carrousel outlier (sur Instagram ou gratuitement sur [topcarousels.com](https://topcarousels.com)) et colle les captures des slides (ou le lien Instagram) dans le chat.
2. Extrais :
   - Le **format exact** (`List`, `Tutorial`, `Cheat Sheet`, `Story`, `Opinion`, `Case Study`, `Showcase`, `Quiz`).
   - La **mécanique du hook** (Slide 1) et le nombre de mots.
   - La **transition Slide 1 → Slide 2** et le rôle de chaque slide suivante.
   - Le type de **CTA final**.
3. Propose **5 idées de remix** pour AI CREATOR Studio en gardant cette structure exacte.

### Route 2 — Relais depuis `viral-brand-analyst`
Utilise `/viral-brand-analyst` (ou `scripts/ig_competitor_spy.py`) sur les comptes de référence de `.agents/perfil.md` ou des comptes de niches adjacentes pour isoler les posts `>= 2.0x` la médiane du compte, puis passe le gagnant à `carousel-studio` (Mode 2 Remix).

### Route 3 — Connecteur MCP Top Carousels (Si activé dans Antigravity)
Si des outils MCP Top Carousels (`search_carousels`, `top_outliers`, `view_slides`, `remix_brief`) sont disponibles dans la session :
1. Appelle `search_carousels` ou `top_outliers` sur le sujet (ou sur une niche voisine pour un remix frais).
2. Ouvre les 2 ou 3 meilleurs multiples avec `view_slides` (ou `remix_brief` si l'utilisateur a collé une URL `topcarousels.com/c/...`).
3. Cite toujours à l'utilisateur les références retenues (compte, multiple vs médiane, lien) avant de rédiger.

*(Si le connecteur n'est pas configuré, ne bloque jamais : mentionne en une ligne qu'il peut coller des captures depuis topcarousels.com, puis poursuis avec la matrice `references/formats-niche-matrix.md`.)*
