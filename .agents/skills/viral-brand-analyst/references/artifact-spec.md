# Spécification du Rapport (DÉCOUVERTE & TEARDOWN)

Tout rapport est rédigé en **français**, orienté action : le verdict d'abord, les preuves ensuite, jamais de remplissage sur ta méthodologie.

**Où livrer le rapport :**
- Directement dans la réponse structurée (ou en Artifact markdown/HTML si l'utilisateur demande un document dédié).
- **Zéro pollution du workspace** : si un fichier HTML ou JSON est généré, le placer dans `/tmp/ig-spy-cache/`.

---

## Structure — MODE TEARDOWN

1. **Verdict** (3–4 phrases en tête) : ce qui s'est passé, pourquoi, label d'attribution (`content-earned` / `distribution-assisted` / `distribution-driven` / `non vérifiable`), et multiple exact par rapport à la médiane.
2. **Les chiffres** : métriques du post face à la médiane du compte (et ratios si observés). Marquer `non vérifié` pour toute donnée manquante.
3. **Le hook (`0–3s`)** : phrase exacte citée verbatim + description du premier frame et du timing.
4. **Map de beats** : tableau timé complet (`Début | Durée | Audio/Fala | Visuel | Rôle`).
5. **Grammaire visuelle & son** : système visuel, rythme, sous-titres, sound design.
6. **Légende & commentaires** : première ligne verbatim, commentaire épinglé, 3–5 commentaires réels cités.
7. **Ce qui est copiable** : 3 groupes distincts (`Réplicable` / `Conditionnel` / `Non réplicable`).
8. **Les règles transférables** : 4 à 7 contraintes concrètes issues de l'observation.
9. **3 Concepts prêts à produire (AI CREATOR Studio)** :
   - Place dans le tunnel (`TOFU` / `MOFU` / `BOFU`) & pilier (`1..5`).
   - Format cible (`Reel Studio Lin 9:16` ou `Carrousel 4:5`).
   - Accroche verbatim en français (voix Abigail Peugh, zéro jargon banni, zéro prix, zéro `—`).
   - Structure par beats + Connecteur Visuel `1..5` + CTA (`CLAUDE` / `PRODUIT`).
   *(Prêt à être transmis tel quel à `content-script-writer`.)*
10. **Ce qu'on n'a pas pu vérifier** : liste courte et honnête.

---

## Structure — MODE DÉCOUVERTE

1. **Ce qu'il faut faire maintenant** : les 3 actions prioritaires en tête.
2. **Ce qui monte (`Ascendant`)** : formats émergents, nombre de comptes indépendants observés (`>= 3`), exemples avec `@handles` et multiples.
3. **Ce qui est saturé / en déclin** : quoi éviter pour ne pas perdre de temps.
4. **Hooks qui fonctionnent** : vrais hooks cités verbatim (source + chiffres + mécanisme), suivis d'adaptations dans la voix d'AI CREATOR Studio.
5. **Trous de marché (`Gaps`)** : questions sans réponse en commentaires, formats de niches voisines, consensus contestables.
6. **3 Concepts prêts à adapter** : même format détaillé que ci-dessus pour enchaîner directement avec `content-script-writer`.
7. **Sources & date d'observation** : 1 paragraphe court en bas (comptes lus, dates, limites éventuelles comme le proxy YouTube Shorts).
