## 6. Sauvegarde des données

Les données que vous saisissez dans l'application **ne sont jamais synchronisées automatiquement dans le cloud ni entre vos différents appareils**. La mémorisation du déverrouillage par code d'accès est distincte de vos données d'utilisation.

*(Note au créateur : conservez uniquement l'option correspondant au fonctionnement réel de votre application.)*

- **Option A (calculateur ou simulateur éphémère) :** Les chiffres et simulations saisis restent uniquement dans le fonctionnement courant de votre navigateur pendant votre session. Ils ne sont pas enregistrés pour une prochaine utilisation après fermeture ou rechargement.
- **Option B (outil avec sauvegarde locale sur l'appareil) :** Vos données restent enregistrées dans le navigateur de l'appareil utilisé (`localStorage`). Elles restent disponibles lors de vos prochaines visites sur ce même appareil et ce même navigateur, hors navigation privée.
