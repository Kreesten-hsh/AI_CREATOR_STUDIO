# Personnaliser le Guide d'Accès Client (Leçon 7)

Ce modèle permet de créer ton **Guide d'Accès Client PDF en 1 page A4** aux couleurs de ton application, prêt à être ajouté sur Chariow.

---

## Étape 1 — Prépare Claude

Ouvre une discussion Claude et joins :
1. Le fichier **`GUIDE-ACCES-CLIENT-MODELE.html`** (téléchargé dans la leçon).
2. Le fichier **`index.html`** de ton application pour que Claude reprenne exactement ses couleurs.

---

## Étape 2 — Copie et complète ce message

Remplace les infos entre crochets `[...]` avant d'envoyer :

```text
Personnalise le fichier GUIDE-ACCES-CLIENT-MODELE.html joint pour créer le Guide d'Accès Client final de mon application.

Voici mes informations exactes :
- Nom de l'application : [NOM DE MON APPLICATION]
- Promesse en 1 phrase : [PROMESSE EN 1 PHRASE]
- Lien Netlify complet : [MON LIEN NETLIFY]
- Code d'accès client : [MON CODE D'ACCÈS]
- Email support (et délai de réponse) : [MON EMAIL SUPPORT]
- Ce qu'il faut préciser sur les données : [Ex : sauvegarde automatique sur l'appareil, ou outil instantané sans sauvegarde]

Consignes :
1. Reprends exactement les couleurs de mon fichier index.html joint, avec un texte bien lisible.
2. Remplace tous les champs entre crochets (y compris le lien du bouton d'accès, le code et le titre de la page).
3. Adapte l'étape 03 selon ma précision sur les données.
4. Garde la mise en page exacte pour que le document tienne proprement sur une seule page A4 sans déborder.
5. Renvoie-moi le fichier HTML complet prêt à ouvrir dans mon navigateur pour l'enregistrer en PDF.
```

---

## Étape 3 — Enregistre ton PDF en 1 page

1. Télécharge le fichier HTML renvoyé par Claude et ouvre-le dans ton navigateur.
2. Vérifie que le lien, le code d'accès et ton e-mail sont exacts (clique sur le bouton d'accès pour tester).
3. Fais **Imprimer > Enregistrer au format PDF** (sur ordinateur : `Ctrl + P` ou `Cmd + P`, format `A4`, marges sur `Aucune`, en activant l'option **Graphiques d'arrière-plan** ; sur téléphone : option *Partager > Imprimer > Enregistrer en PDF*).
4. Vérifie que le document tient bien sur **1 seule page**, puis ajoute ce PDF à ta fiche produit Chariow.
