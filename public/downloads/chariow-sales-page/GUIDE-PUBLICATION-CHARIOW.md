## 5. Description Visuelle du Produit (Import Sans Erreur `100 000 caractères` et `< 2 MB`)

Dans l'éditeur de description du produit sur Chariow :

1. **Supprime d'abord toute ancienne image** présente dans le bloc description.
2. **Clique impérativement sur l'icône Image de la barre d'outils** pour sélectionner le fichier depuis ton ordinateur (`Chariow` téléverse alors l'image sur son CDN et n'insère qu'une courte adresse de `~225` caractères).
   - **Ne jamais faire `Ctrl+C / Ctrl+V` ni glisser-déposer** un PNG directement dans l'éditeur : cela colle l'image en Base64 dans le texte HTML et déclenche immédiatement l'erreur *« Le texte de description ne peut pas contenir plus de 100000 caractères »* dès la 1re tranche.
3. Choisis ensuite l'une des 2 options (tous les fichiers ci-dessous pèsent moins de `2 MB`) :
   - **Option A (Recommandée, 9 tranches dans l'ordre exact, sans ligne vide entre elles)** :

     2. `02-mockup-studio-interieur.png`
     3. `03-storytelling-constat.png`
     4. `04-piliers-interactivite.png`
     5. `05-preuve-sociale-retours.png`
     6. `06-tout-ce-qui-est-inclus.png`
