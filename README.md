# AI CREATOR Studio

> Plateforme interactive d'apprentissage et studio de création de produits digitaux néo-brutalistes avec Claude AI.

---

## Présentation

**AI CREATOR Studio** est une plateforme web interactive conçue pour accompagner les créateurs dans la transformation de documents statiques (PDF, guides texte) en expériences digitales interactives à fort engagement, pages de vente éditoriales et workflows d'automatisation.

L'interface adopte une esthétique **Néo-Brutaliste Éditoriale** inspirée des publications imprimées suisses et des starter kits contemporains (palette rouge brique, rose poudré et crème papier, typographie à fort contraste, bordures franches de 2px et ombres décalées).

---

## Structure Pédagogique

Le studio s'articule autour de **5 modules** et **25 leçons guidées** :

- **Bien commencer : Maîtriser Claude** (2 leçons d'orientation et configuration du profil créateur)
- **Module 1 : Offre & Fondations de l'IA** (Leçons 01 à 05)
  - Définition de niche, psychologie de l'acheteur, positionnement et plan de produit.
- **Module 2 : Du PDF à l'Expérience Interactive** (Leçons 06 à 10)
  - Déconstruction de contenu, architecture Claude Artifacts, calculateurs embarqués et sauvegarde locale.
- **Module 3 : Pages de Vente Éditoriales** (Leçons 11 à 15)
  - Récit de vente, section hero avec démonstrateur interactif, visite du curriculum et offre.
- **Module 4 : Studio d'Automatisation** (Leçons 16 à 20)
  - Micro-lead magnets, flux conversationnels ManyChat, webhooks n8n et séquences de relance.
- **Module 5 : Usine à Contenu & Lancement** (Leçons 21 à 25)
  - Carrousels graphiques néo-brutalistes, scripts de démonstration vidéo et plan de lancement sur 7 jours.

Chaque leçon suit un rythme invariable en 4 étapes :
1. **Comprendre** : Cadre stratégique et vidéo de briefing.
2. **Prompt Claude** : Compilateur dynamique injectant les variables de profil.
3. **Exemple guidé** : Structure de référence et fiches pratiques téléchargeables.
4. **À vous de jouer** : Espace de travail avec persistance automatique et liste de validation.

---

## Stack Technique

- **Framework** : React 18
- **Langage** : TypeScript (mode strict)
- **Build tool** : Vite 6
- **Styling** : Tailwind CSS avec design tokens néo-brutalistes sur mesure
- **Animations** : Framer Motion
- **Iconographie** : Lucide React
- **Tests** : Vitest
- **Persistance** : LocalStorage avec synchronisation d'état réactive

## Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/Kreesten-hsh/AI_CREATOR_STUDIO.git
cd AI_CREATOR_STUDIO

# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Lancer la suite de tests unitaires
npm run test

# Vérifier les types TypeScript
npm run typecheck

# Compiler pour la production
npm run build
```
